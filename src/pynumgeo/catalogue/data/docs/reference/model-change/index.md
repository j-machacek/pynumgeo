# Model change
```numgeo 
*Model change, <method>
```

!!! note "Release information"

    `*Model change` was introduced in the [November 2025 release](../../release/release_notes_2025_11.md).

This option allows you to modify essential model settings during analysis, such as element material specifications. Model changes are applied at the beginning of a step. Currently supported `<method>` values are:

* [Material](./material.md)
* [Remove](./elements.md) and [Add](./elements.md) elements
* [Friction](./friction.md): parameters of the friction model of an interaction
